# AI Engineering

Experiments, notebooks, and models for learning AI by building it.

- [Transformer digit reversal](transformers/digit-reversal/) — Train a tiny encoder–decoder and inspect the math. [Live demo](https://singhcoder.github.io/ai-engineering/digit-reversal/).
- [From waveform to mel spectrogram](docs/visualizations/mel-spectrogram/) — Follow an audio frame from waveform to frequency bins to mel bands. Open the directory’s `index.html` locally; no dependencies.
