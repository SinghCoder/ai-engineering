How Word2vec learns from neighbors

Cover up cat in “the cat eats fish.” Can a model use the and eats to fill the gap? Follow one guess, correct it once, and see which numbers change.

1. Build one guess

the ? eats fish

With a one-word window on either side, the model looks up the and eats in its input table. Each row holds two numbers. At the start of training those numbers are random. Average the two rows to make one vector for the clues. That average is the “bag” in CBOW: swapping the two clues leaves it unchanged.

Now compare that clue vector with each candidate’s row in a separate output table. The input row represents a word when it’s a clue; the output row scores it when it’s a possible answer. The same word can play both roles, but the two rows are learned independently.

A score isn’t a probability. Softmax exponentiates every score and divides by the sum, so all 12 probabilities add to one. The correct answer in this sentence is cat. Its probability determines the loss: a lower probability means a larger correction signal.

See all 12 scores and the softmax denominator

2. Correct that guess once

Look at the second weight in the output row for cat. The second component of the clue vector is negative. To raise the dot product, should that weight go up or down?

Why is the gradient p(cat) − 1?

First differentiate the loss with respect to the score, then the score with respect to the weight.

−ln p(cat) = ln Σ exp(score[word]) − score[cat]

The derivative of the first term with respect to the cat score is its softmax probability. The derivative of −score[cat] is −1. Finally, the derivative of the cat score with respect to its second output weight is just clue feature 2: that’s the number multiplying the weight in the dot product. Multiply these two derivatives to get the weight gradient.

That step trains a prediction, not a dictionary definition. Next, change what the model gets to see and what counts as a correct answer.

3. Turn the prediction around

Keep cat selected and flip to Skip-gram. The center word now supplies the input vector. The neighbors become separate targets: score the on one training pair and eats on another. Both use the same softmax over the vocabulary; there isn’t a separate left or right output slot.

4. Can two words become neighbors without meeting?

The six training sentences never put cat and dog together. In the original corpus they share contexts. In Skip-gram, their input vectors keep getting asked to score the same neighbors; in CBOW, both words get trained as answers to the same clue vectors. Those shared prediction jobs can encourage similarity, but the loss never directly tells their input vectors to point in the same direction. Check where dog ends up, then change only its two sentences. Both runs start with the same weights.
