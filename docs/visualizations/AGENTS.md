# Interactive explanations

Read the Atlas explorable visualization skill before creating or revising an interactive lesson. On Atlas Lightsail it is at `/var/lib/atlas-chat/.codex/skills/atlas-explorable-visualizations/SKILL.md`. Start by choosing a relevant PAIR interaction and a specific thing the reader can discover.

Standalone lessons can start from `editorial.css` and its self-hosted DM Sans. Use a white canvas, an article-width introduction, and wider figures where the data needs them. Start with the first experiment and put controls next to the evidence they affect. Use a shared cursor or selection when showing successive stages of a transformation. Look at the rendered page at desktop and phone widths, then exercise the central interaction before publishing.

Write in the reader’s order of discovery. Lead with a concrete action and an observation, then name the mechanism. Give each sentence an active subject where it helps. State results directly, compare the specific conditions the figure shows, and reserve bold for a term or label the reader needs to find.
