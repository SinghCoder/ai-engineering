# How Word2vec learns from neighbors

[Live explorable](https://singhcoder.github.io/ai-engineering/visualizations/word2vec/) · [Jupyter notebook](word2vec.ipynb)

Open the notebook in Jupyter with a Python 3 kernel and run all cells. The training code needs no packages. Change the corpus, window radius, or objective and rerun from the configuration cell.

The explorable replays reproducible checkpoints from the same trainer. From this directory, run `python3 build.py` to regenerate the notebook and browser checkpoint data. Run `python3 -m unittest discover -s word2vec` from the repo root to check the training math.
